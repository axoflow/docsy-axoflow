{{- /* The PDF edition's file name: `-.pdf`, lowercased, whitespace in the product name turned into hyphens ("AxoSyslog Core" 0.12.0 → axosyslog-core-0.12.0.pdf). Empty when either param is missing. A partial build (`params.pdf.root`, see pdf/root.html) appends the root page's path: axoflow-0.90-deploy-appliance-install.pdf. CI never sets it, so the published name and the download link are unaffected. The one place the name is decided. Everything else reads it from here, never recomputes it: - pdf/download-link.html links to it, next to the version's own pages - layouts/docs/baseof.pdf.html and hooks/head-end.html emit it as , which scripts/pdf/build.sh names the output after and the publish workflows upload and protect under */ -}} {{- $name := "" -}} {{- with site.Params.product_name -}} {{- $product := . | lower | strings.TrimSpace | replaceRE `\s+` "-" -}} {{- with site.Params.version_tag -}} {{- $suffix := "" -}} {{- with site.Param "pdf.root" -}} {{- $suffix = printf "-%s" (strings.Trim (. | lower | replaceRE `[^a-z0-9]+` "-") "-") -}} {{- end -}} {{- $name = printf "%s-%s%s.pdf" $product . $suffix -}} {{- end -}} {{- end -}} {{- return $name -}}
