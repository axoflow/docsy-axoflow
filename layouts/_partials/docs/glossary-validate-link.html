{{/* Validates one term's `full_link` against the site, and reports through the same channel the markdown link render hook uses. WHY THIS EXISTS. `full_link` is front matter, not markdown, so _markup/render-link.html never sees it — the one internal link on a glossary term is the one link on the site that nothing checks. A renamed target page leaves every tooltip for that term pointing at a 404, silently, and the glossary is exactly where a stale link costs most: it is the page a reader goes to when they are already unsure. Honours `params.render_hooks.link.errorLevel` rather than always failing, so the glossary reports at whatever level the site already chose for its markdown links. Fragments go to the render hook's own `validate-fragment` inline partial. That is deliberate reuse and not just economy: it carries three fallbacks a naive `.Fragments.Identifiers` check does not have — hand-placed `` anchors, anchors that arrive through an include-headless snippet, and the `skip_fragment_validation` opt-out for pages whose anchors a shortcode generates at render time. Reimplementing it here would report false breakage on all three. Call through `partialCached` keyed by the term id: the message then appears once per build rather than once per tooltip. @context {page} The glossary term page. */ -}} {{- $term := . -}} {{- with $term.Params.full_link -}} {{- $errorLevel := or site.Params.render_hooks.link.errorLevel "ignore" | lower -}} {{- if ne $errorLevel "ignore" -}} {{- $link := . -}} {{- $u := urls.Parse $link -}} {{- $contentPath := $term.Path -}} {{- with $term.File -}} {{- $contentPath = .Path -}} {{- end -}} {{- if $u.IsAbs -}} {{/* An absolute URL is only wrong when it points back at THIS site: that is the hardcoded internal link the style guide forbids, and it should be a path so the link survives a move. A URL somewhere else is legitimate and is left alone. The sibling documentation sets are the case that matters — AxoSyslog's docs sit at axoflow.com/docs/axosyslog-core/ while this site is at axoflow.com/docs/axoflow/ — so comparing hosts would reject them. The test is the whole site root, not the host. site.Home.Permalink rather than site.BaseURL because it is resolved in every environment; config/_default sets baseurl to "/". The cost is that a hardcoded internal URL goes unreported on a development build and is caught on the production one, which is what CI runs. */ -}} {{- if hasPrefix $link site.Home.Permalink -}} {{- $msg := printf "glossary term %q sets full_link %q as an absolute URL into this site; use a site-relative path" $contentPath $link -}} {{- if eq $errorLevel "error" }}{{ errorf $msg }}{{ else }}{{ warnf $msg }}{{ end -}} {{- end -}} {{- else -}} {{- with $u.Path -}} {{- $p := or (site.GetPage .) (site.GetPage (strings.TrimRight "/" .)) -}} {{- if not $p -}} {{- $msg := printf "glossary term %q has an unresolvable full_link %q" $contentPath $link -}} {{- if eq $errorLevel "error" }}{{ errorf $msg }}{{ else }}{{ warnf $msg }}{{ end -}} {{- else -}} {{- with $u.Fragment -}} {{- partial "inline/h-rh-l/validate-fragment.html" (dict "contentPath" $contentPath "errorLevel" $errorLevel "page" $p "parsedURL" $u "position" (printf "%s (full_link)" $contentPath) "renderHookName" "glossary_tooltip" ) -}} {{- end -}} {{- end -}} {{- end -}} {{- end -}} {{- end -}} {{- end -}}
